# DWG Drawing Parser

Convert DWG, DXF and SVG drawings from URLs into PNG previews, SVG pages,
native text with positions, and a searchable metadata index. The plugin runs
the [dwg-apify Actor](https://apify.com/aileron-tech/dwg-apify), then reads its
Apify dataset. It supports batches of up to 1,000 drawing URLs, each up to
100 MB.

Sign in with your Apify account when prompted. Apify runs the conversion,
stores the run output and applies per-drawing pricing to your account. See
[prices](https://apify.com/aileron-tech/dwg-apify/pricing) and
[Apify's privacy policy](https://apify.com/privacy-policy).

Try asking Claude to parse the
[Autodesk blocks and tables drawing](https://download.autodesk.com/us/samplefiles/acad/blocks_and_tables_-_imperial.dwg)
and report the number of pages and native text labels.
